01

LineTracker

Featured
Real-time stock price & sports-odds alerts, delivered by email.

Set a target for a stock price or a sports betting line and LineTracker emails you the moment it's hit. It's my most technically involved project — a multi-user Flask backend running scheduled jobs against live data feeds, with a React front end for managing your alerts.

Highlights

  • Background scheduler (APScheduler) polling live odds and stock data, with a Flask in-memory cache to stay under API rate limits.
  • Multi-user support via email-based filtering — the client stores your email in localStorage and the server filters alerts per user.
  • Email notifications through Brevo; migrated SQLite → PostgreSQL for persistent storage on Render.
  • UptimeRobot pings keep the free instance warm so the scheduler never dies on spin-down.

02

YouTube Video Summarizer

Paste a link, get an AI summary tuned to your level — with audio playback.

Drop in any YouTube URL and get a clean summary written for the depth you choose — Beginner, Intermediate, or Expert. Built around Claude for the summarization and a transcript service for the source text, with browser-native text-to-speech so you can listen instead of read.

Highlights

  • Three audience levels (Beginner / Intermediate / Expert), driven by careful prompt engineering.
  • Anthropic Claude API for summaries (chose claude-haiku-4-5 over Opus for cost efficiency); transcripts via Supadata.
  • Transcript caching to avoid repeat fetches, plus browser-native TTS for audio playback.
  • Full-stack Flask + React, fully deployed.
